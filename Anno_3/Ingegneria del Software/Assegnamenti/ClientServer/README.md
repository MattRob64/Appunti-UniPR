## Step-by-step guide on how to use this product server application

### STEP 1: OPEN THE PROJECT IN THE PREFERRED IDE
1. Open your preferred IDE (e.g. Eclipse, IntelliJ, NetBeans, ecc...)
2. Open the project

### STEP 2: GET TO KNOW THE PROJECT STRUCTURE
1. The main Java files are located in /src/main/java/
2. Inside the java folder there is a package called com.robuschi, all the java files are located there (note that in the file explorer the package is usually shown as /com/robuschi)

### STEP 3: BRIEF EXPLANATION OF THE CLASSES
### Server
Server application that manages product sales to multiple clients and listen on the port 5555.

Generates random prices and handles purchase requests from clients.
### Client
Client application that connects to the product server and makes purchase decisions based on randomly generated maximum purchase prices.

###### For a more in-depth look at the functionality of the class read the Javadoc.

### STEP 4: EXECUTION

1. Run 'Server.main()'
2. Wait for the message "Server started on port 5555 Waiting for clients to connect..." to appear
3. Run 'Client.main()' if you want the client application to start with only 3 users.
4. Run 'Client.main(args)' with agrs>3 if you want the client application to start with the number of users that you set.
5. Wait for the message "Starting N clients..." to appear
6. Once the application starts the server will start generating random prices based on the parameters given in the class and the clients will start generating random purchase requests
7. If the client's prices of the purchase request is greater than the product price generated by the server the purchase is successful
8. A client disconnects after a total of 10 successful purchases
9. The server stops only after all the connected clients conclude their purchases

### Example Execution Flow

* Server starts and waits for connections
* Three clients connect to the server
* Server begins price generation (e.g., €45)
* Each client receives price and generates max price:
* Client 1: Max €60 → Purchases
* Client 2: Max €30 → Skips
* Client 3: Max €50 → Purchases
* Process repeats until each client has 10 purchases
* Clients notify completion and disconnect
* Server detects all completions and shuts down
