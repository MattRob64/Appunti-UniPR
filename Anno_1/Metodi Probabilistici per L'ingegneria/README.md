# Appunti Di Metodi Probabilistici per l'Ingegneria
 Documento LaTeX contenente i miei appunti presi a lezione sistemati e revisionati. <br>
 In questa repository sono contenuti i seguenti file:
 - <Strong>Appunti Metodi</strong>: Appunti presi a lezione e sistemati
 - <Strong>DimTeoMetodi</Strong>: Indice separato dal documento principale contenente le varie pagine in cui si possono trovare i vari teoremi e le rispettive dimostrazioni
 - <Strong>FormularioMetodi</Strong>: Semplice formulario originato dagli appunti

 P.S. Un'ulteriore revisione di questi appunti sarebbe convertire le varie foto in LaTeX per alleggerire e ulterioremente organizzare il file.
